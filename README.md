# Wayy2Flyyy FiveM Enhanced Experience

**Wayy2Flyyy FiveM Enhanced Experience** is a fully custom overhaul of FiveM frameworks, designed to make your server feel cleaner, smoother, and more refined from the moment it starts.

Built as a simple drag-and-drop, this project improves the default FiveM experience with enhanced UI, better structure, cleaner resources, and a more polished overall server feel.

It is completely free, open to the community, and built for developers who want to expand, improve, and make it their own.
