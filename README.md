# Wayy2Flyyy Qbox Enhanced Experience

**Wayy2Flyyy Qbox Enhanced Experience** is a fully custom overhaul of the Qbox framework, designed to make your server feel cleaner, smoother, and more refined from the moment it starts.

Built as a simple drag-and-drop, this project improves the default Qbox experience with enhanced UI, better structure, cleaner resources, and a more polished overall server feel.

It is completely free, open to the community, and built for developers who want to expand, improve, and make it their own.

**Beta release: 17th May 2026**
